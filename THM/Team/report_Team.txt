[LESSONS LEARNED]
1. Development sites often have vulnerabilities (LFI in this case)
2. Subdomain enumeration is critical - found dev.team.thm
3. PHP filter wrappers can be used for base64 encoding
4. robots.txt can contain hints (found "dale" user)
5. LFI can be used to read sensitive files, including flags
6. SSH private keys can be stored in unexpected places like sshd_config comments
7. Privilege escalation paths: dale -> gyles (sudo) -> root (writable cron script)
8. FTP credentials can be found in .old backup files in web directories
